## 👨‍💻 Обо мне

Я **Python backend developer и ML engineer** из Бишкека. Разрабатываю REST API и backend-сервисы, а также ML/AI-проекты — от обучения моделей до их интеграции в приложения.

- 🔧 Делаю backend на **Django, DRF и FastAPI**, строю архитектуру сервисов и оптимизирую API
- ⚡ Работаю с **WebSocket**, асинхронными задачами и **Redis**
- 🐳 Разворачиваю проекты на **Linux-серверах** через **Docker Compose + Nginx**
- 🧠 Создаю проекты на стыке **машинного обучения, Computer Vision и LLM**
- 📚 1.5 года учился в **Motion Web Academy** (направление Python backend / ML) с хорошей успеваемостью
- 🚀 Быстро учусь и люблю решать сложные технические задачи

## 🚀 Проекты

### 🛒 [AvitoPython49](https://github.com/KadyrovErjan/AvitoPython49)
**REST API для онлайн-доски объявлений в стиле Avito**

Полноценный backend маркетплейса: каталог, корзина, избранное и отзывы.

- 🔐 JWT-авторизация (access / refresh, blacklist токенов) и вход через GitHub / Google
- 🗂 Категории → подкатегории → товары с фото и видео
- 🔎 Поиск, фильтры по цене и подкатегории, сортировка и пагинация
- ⭐ Отзывы с рейтингом, корзина с подсчётом суммы, избранное
- 🌍 Мультиязычность EN / RU через `django-modeltranslation`
- 📚 Swagger-документация и деплой через Docker Compose (Gunicorn + PostgreSQL + Nginx)

`Python` `Django` `DRF` `JWT` `PostgreSQL` `Docker` `Nginx` `Swagger`
